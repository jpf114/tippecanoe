## 3. china 基准复现

```bash
# 1) vcpkg 对照版（build/dynamic 旧产物，如存在）与 vendor 版各跑一次
./tippecanoe-db -f -Z0 -z8 -o /tmp/reg.mbtiles \
  --postgis postgresql://postgres:postgres@127.0.0.1:5432/TippTest \
  --postgis-table china --postgis-geometry-field geom

# 2) tiles 表逐行比对（排除 metadata 的路径噪声）
sqlite3 /tmp/reg.mbtiles \
  "select zoom_level||':'||tile_column||':'||tile_row||':'||hex(tile_data)
   from tiles order by zoom_level,tile_column,tile_row;" | md5sum
# 期望：6030fbe69e07d5d12cb677fce4b099b2
```
